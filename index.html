Featured — Hackathon Project
ShadowOps: Engineering Risk Intelligence for GitHub CI

Built at DevDash 2026 — ShadowOps transforms GitHub CI workflow telemetry into actionable engineering risk intelligence. It computes a deterministic 7-day risk score, clusters failures by workflow, detects trends (increasing/decreasing/stable), and generates AI-powered incident reports with remediation steps. The architecture flows from GitHub REST API through a custom Risk Engine, pattern detection, and into an interactive Next.js + Recharts dashboard.
